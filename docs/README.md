# SciFigQual-Bench project page

GitHub Pages site for the benchmark (not a separate product demo).

- Live URL (after enabling Pages): https://frankdengai.github.io/SciFigQual-Bench/
- Source: `docs/index.html` + `docs/assets/`

## Enable Pages

1. Push this repository to `FrankDengAI/SciFigQual-Bench`
2. GitHub → **Settings** → **Pages**
3. Source: **Deploy from a branch**
4. Branch: `main` (or `master`) · Folder: `/docs`
5. Save — wait 1–2 minutes for the green live URL
