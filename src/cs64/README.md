# `src/cs64/` — Core library

The project's importable core library (`from cs64.<module> import ...`).
Currently only `data/` (unified HF/local Parquet I/O) and `features/`
(OCR/CV feature schema + extraction) have substantive implementations;
`config/`, `judge/`, `pipeline/`, `utils/` are reserved.
